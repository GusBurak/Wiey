# Qu'est-ce qu'on mange ?
(dépôt « Wiey »)

Tentative de code pour la première fois : idée d'une application ou je peux rentrer tout ce que je mange.

## Lancer le site
Ouvrir `index.html` dans un navigateur. Aucune installation nécessaire.

- `index.html` : structure de la page (menu à gauche, calendrier en pleine page avec le bouton « Ajouter un repas »)
- `styles.css` : apparence
- `smartcrop.js` : miniatures recadrées sur l’assiette
- `app.js` : comportement (calendrier, aperçu au survol, détails au clic, ajout de repas)

Les repas sont enregistrés dans le navigateur (localStorage). Le site démarre vide : seuls les repas ajoutés par l’utilisateur sont affichés.
